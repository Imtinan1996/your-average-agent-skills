Findings

    Select lines, then use the button beside the selection (or press c) to copy a reference for an AI agent. Click a line number to open it in your editor. Press ? for shortcuts.

    Keyboard shortcuts

    j / kNext / previous file
    n / pNext / previous change (hunk)
    xCollapse or expand the current file
    Shift + XCollapse or expand every file
    vMark the current file viewed (collapses it, moves on)
    c / Shift + CCopy the selection as a reference / with code
    sCopy the change summary
    oOpen the current file in your editor
    f / Shift + FNext / previous finding
    /Filter files by path
    gGo to a reference (paste path:line or a copied reference)
    EscClose this, clear the selection toolbar
